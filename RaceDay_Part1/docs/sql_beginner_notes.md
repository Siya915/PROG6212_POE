# RaceDay SQL — Beginner Notes

The script is intentionally written with simple SQL statements.

- `CREATE DATABASE` creates the RaceDay database.
- `USE` tells SQL Server which database to work with.
- `CREATE TABLE` creates each table.
- `PRIMARY KEY` uniquely identifies each record.
- `FOREIGN KEY` connects related tables.
- `NOT NULL` means a value is required.
- `UNIQUE` prevents duplicate values.
- `DEFAULT` supplies a value automatically when one is not provided.
- `CHECK` makes sure a value follows a rule.
- `INSERT INTO` adds sample records.
- `SELECT *` displays the records so the student can check the result.

The script is intended to be run once on a clean SQL Server instance, as required by the assignment.
